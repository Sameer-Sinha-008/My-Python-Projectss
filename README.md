## 🎮 Featured Projects & Code Lab

### 🤖 1. Smart Assistant CLI v3.0 (`smart_assistant.py`)
* **Kya hai?** Ek All-in-One CLI Tool jo daily tasks ko automate aur simple banata hai.
* **Speciality:** 
  * ⏰ **JARVIS Real-Time Greeting:** Time ke hisab se (Morning/Evening) smart greeting aur date/time batata hai (`datetime`).
  * 🧮 **Advanced Calculator:** Basic arithmetic, square roots, squares, aur powers handle karta hai.
  * 🕵️‍♂️ **Secret Agent Cipher:** Text encoding/decryption system (ASCII shift logic).
  * 🌐 **Universal Translator:** Multi-language translation support using `deep-translator`.
  * 📝 **Permanent Notes Vault:** File Handling (`open`, `write`, `read`) ka use karke notes/passwords ko phone storage mein permanently save rakhta hai.

### 🎮 2. Game Character Health Manager (`game_oop.py`)
* **Kya hai?** OOPs (Object-Oriented Programming) ka use karke ek gaming character engine banaya hai.
* **Speciality:** Isme `@property` aur `@health.setter` lagaya hai taaki character ki health kabhi 100 se zyada aur 0 se kam na ho sake! Ekdum game rule validation!

### 🎰 3. Lucky Number Casino Game (`lucky_number_casino.py`)
* **Kya hai?** Ek mazedar betting/casino game jahan user apna lucky number test kar sakta hai logic aur loops ke saath.

### 📐 4. AP Calculator (`AP_Calculator.py`)
* **Kya hai?** Maths ki Arithmetic Progression (AP) solve karne ke liye calculator jo series ka kaam aasan kar deta hai.

### 🧪 5. Chemistry Valency Solver (`Chemistry_Valency_Solver.py`)
* **Kya hai?** Elements ki valency aur chemistry concepts ko fast check karne ke liye banaya gaya script.

### ✊✌️✋ 6. Rock Paper Scissors (`rock_paper_scissors.py`)
* **Kya hai?** Classic game jisme computer ke random moves ke khilaf user apna dimaag lagata hai.

### 🧠 7. OOPs Mastery Lab (`oops_practice.py`)
* **Kya hai?** Programming ke core concepts jaise Inheritance aur Access Modifiers (Private/Public variables) ko sikhne ke liye advanced practice files.

### 🕵️‍♂️ 8. Secret Agent Cipher System (`secret_agent_cipher.py`)
* **Kya hai?** Cyber-security aur cryptography par based ek hacker tool jo tumhare messages ko ek secret code me badal deta hai!
