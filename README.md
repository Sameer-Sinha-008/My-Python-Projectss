# 🚀 Featured & Advanced Projects (Core OOPs & Systems)

### 1. 🤖 Smart Assistant CLI v3.0 (`smart_assistant.py`)
* **Overview:** An All-in-One CLI tool automating daily tasks.
* **Features:** Real-time JARVIS Greetings, Advanced Calculator, Secret Agent Cipher, Universal Translator, and Notes Vault.

### 2. 🚖 Olaber Ride-Booking CLI System (`olaber_cab.py`)
* **Overview:** Advanced OOP-driven ride-booking CLI engine featuring real-time surge pricing, automated vehicle allocation, and interactive simulation.
* **Key Concepts:** Python `datetime` for peak hour detection (17:00–21:00), OOP Inheritance (`Vehicle`, `MiniCab`, `XLCab` subclasses), `super().__init__()`, and dynamic fare logic (Normal: ₹50/km, Peak: ₹80/km).

### 3. 🏧 Smart ATM Engine (`atm_engine.py`)
* **Overview:** An OOP-driven CLI ATM engine with strict security checks, deposit/withdrawal validation, and real-time state updates.
* **Key Concepts:** Encapsulation (Private attributes `__balance` & `__pin`), type casting, string formatting (`:.2f`), and control flow.

### 4. 🕵️‍♂️ Office Heist - Text Adventure Engine (`office_heist.py`)
* **Overview:** A dynamic, state-driven CLI heist game where the player navigates an office map to delete a file while bypassing locked doors and evading a roaming AI Boss.
* **Key Concepts:** Nested Dictionaries for room state-mapping, inventory gatekeeping, and dynamic NPC movement using Python's `random` module.

### 5. 💰 Student Finance Manager 2.0 (`student_finance_manager.py`)
* **Overview:** Interactive menu-driven CLI finance manager that tracks student budget allocations and delivers automated spending risk analysis.
* **Features:** Stateful `while` loop architecture, real-time percentage breakdown for Rent/Food/Other expenses, and dynamic multi-condition alert warnings.

### 6. 🎮 Game Character Health Manager (`game_oop.py`)
* **Overview:** Gaming character engine built with OOPs concepts.
* **Features:** Uses `@property` and `@health.setter` to strictly validate health rules (0–100 limit).
