## 🎮 Featured Projects & Code Lab

### 1. Game Character Health Manager (`game__oop.py`)
* **Kya hai?** OOPs (Object-Oriented Programming) ka use karke ek gaming character engine banaya hai.
* **Speciality:** Isme `@property` aur `@health.setter` lagaya hai taaki character ki health kabhi `100` se zyada aur `0` se kam na ho sake! Ekdum game rule validation!

### 🎰 2. Lucky Number Casino Game (`Lucky-number-casi...`)
* **Kya hai?** Ek mazedar betting/casino game jahan user apna lucky number test kar sakta hai logic aur loops ke saath.

### 📐 3. AP Calculator (`AP_Calculator.py`)
* **Kya hai?** Maths ki Arithmetic Progression (AP) solve karne ke liye calculator jo series ka kaam aasan kar deta hai.

### 🧪 4. Chemistry Valency Solver (`Chemistry_Valency...`)
* **Kya hai?** Elements ki valency aur chemistry concepts ko fast check karne ke liye banaya gaya script.

### ✊✌️✋ 5. Rock Paper Scissors (`Rock-paper-scissor...`)
* **Kya hai?** Classic game jisme computer ke random moves ke khilaf user apna dimaag lagata hai.

### 🧠 6. OOPs Mastery Lab (`Access_modifiers` & `Inheritance_practic...`)
* **Kya hai?** Programming ke core concepts jaise Inheritance aur Access Modifiers (Private/Public variables) ko sikhne ke liye advanced practice files.
